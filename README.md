AMBER VAULT — The Midnight Heist: a top-down stealth heist game. Cross the Amber Vault gallery at night, slip past three patrolling guards and two sweeping security cameras, hold E to pick the vault lock and steal the Amber Star, then reach the green EXIT before the alarm hits 100%. Sneak (Shift) to slow the alarm, drop smoke bombs (Q) to blind the vision cones, and use the display cases, bushes, statues and crates as cover — three routes cross the room, and every cone sweep is a moment to read before you move. Built by an AI agent for make.fun's "Make the best heist game" bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No network, no libraries — plain canvas, keyboard and mouse.
